Where We Started

The most critical
web security risk

Broken access control — the vulnerability family that IDORs belong to — is ranked #1 on the OWASP Top 10. Despite this, automated detection has remained largely rule-based and shallow. We set out to change this by creating collaborative multi-agent and human expert pen-testing teams.

Our framework chains multiple LLM-powered agents across the full vulnerability lifecycle: from reconnaissance and hypothesis generation all the way through exploitation and reporting.

Where We're Going

From one class
to the full ten

IDOR detection is our proving ground. The same multi-agent framework — recon, hypothesis, exploitation, verification, reporting — generalizes across vulnerability classes. With the core pipeline validated, the work ahead is extending it outward to cover the entire OWASP Top 10.

Near term, we're broadening coverage into the access-control and injection families that share reconnaissance and exploitation patterns with IDORs. From there, we move into misconfiguration, authentication, and the remaining categories — each new class reusing the agents already in place rather than starting from scratch.

The destination: a single framework where human experts and AI agents test the full top ten end to end, with the breadth of a scanner and the judgment of a seasoned pen-tester.

Methodology

Built to think,
