A multi-agent LLM framework that automates the full pipeline of hypothesis generation, testing, and exploitation of Insecure Direct Object Reference vulnerabilities in web applications.

Background

The most critical
web security risk

Broken access control — the vulnerability family that IDORs belong to — is ranked #1 on the OWASP Top 10. Despite this, automated detection has remained largely rule-based and shallow. We set out to change that with agents that reason like a skilled pentester.

Our framework chains multiple LLM-powered agents across the full vulnerability lifecycle: from reconnaissance and hypothesis generation all the way through exploitation and reporting.

Methodology

Built to think,
not just scan.

Each agent leverages bleeding-edge LLM agent technologies and techniques to reason through the vulnerability pipeline rather than execute hardcoded rules.
